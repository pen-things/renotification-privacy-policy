1. Pendahuluan 1. Introduction

ReNotification! adalah aplikasi Android yang membantu mengelola dan mengingatkan pengguna tentang notifikasi tertentu. Kebijakan ini menjelaskan bagaimana aplikasi mengakses, menggunakan, menyimpan, dan melindungi informasi di perangkat Anda.

ReNotification! is an Android application that helps users manage and receive reminders about selected notifications. This policy explains how the app accesses, uses, stores, and protects information on your device.

Prinsip utama: Informasi diproses secara lokal. ReNotification! tidak memiliki server pengumpulan data pengguna.

Core principle: Information is processed locally. ReNotification! does not operate a user data collection server.

2. Informasi yang Diakses 2. Information Accessed

Bergantung pada fitur yang Anda gunakan, aplikasi dapat mengakses informasi berikut:

Depending on the features you use, the app may access:

  • Informasi notifikasi dari aplikasi yang Anda pilih.
  • Nama aplikasi sumber notifikasi.
  • Konten notifikasi yang diperlukan untuk fungsi pengingat.
  • Preferensi dan konfigurasi pengingat.
  • Pengaturan suara atau file ringtone pilihan Anda.
  • Notification information from apps you select.
  • The source application name.
  • Notification content required for reminder functionality.
  • Reminder preferences and configurations.
  • Sound settings or ringtone files you select.

Informasi tersebut diakses hanya sejauh diperlukan untuk menjalankan fungsi aplikasi.

This information is accessed only to the extent necessary for the app's functionality.

3. Penggunaan Informasi 3. Use of Information

Informasi digunakan untuk:

Information is used to:

  • Mendeteksi notifikasi yang sesuai dengan aturan Anda.
  • Membuat dan mengelola sesi pengingat.
  • Menampilkan riwayat notifikasi yang relevan.
  • Menjalankan fitur suara dan pengingat.
  • Menyimpan preferensi aplikasi.
  • Detect notifications matching your rules.
  • Create and manage reminder sessions.
  • Display relevant notification history.
  • Run reminder and sound features.
  • Save app preferences.

Informasi notifikasi tidak digunakan untuk iklan, profil pengguna, atau pelacakan lintas aplikasi.

Notification information is not used for advertising, user profiling, or cross-app tracking.

4. Penyimpanan Data 4. Data Storage

Data aplikasi disimpan secara lokal di perangkat Android Anda menggunakan penyimpanan internal aplikasi.

App data is stored locally on your Android device using the app's internal storage.

Penyimpanan lokal meliputi:

Local storage includes:

  • Database lokal untuk data pengingat dan riwayat.
  • Data preferensi dan konfigurasi aplikasi.
  • Data sementara untuk pemulihan fungsi tertentu.
  • Local database for reminder data and history.
  • App preferences and configuration data.
  • Temporary data for certain recovery functions.

Database utama dan file preferensi pemulihan volume sementara dikecualikan dari backup Android. Preferensi aplikasi tertentu yang tidak sensitif dapat disertakan dalam backup sistem Android sesuai pengaturan perangkat Anda.

The main database and temporary volume-recovery preference file are excluded from Android backups. Certain non-sensitive app preferences may be included in Android system backups depending on your device settings.

5. Berbagi dan Pengiriman Data 5. Data Sharing and Transmission

ReNotification! tidak mengirim informasi notifikasi, riwayat, atau data pribadi Anda ke server pengembang.

ReNotification! does not send notification information, history, or personal data to developer servers.

  • Tidak memiliki akun pengguna.
  • Tidak memiliki server pengumpulan data.
  • Tidak menggunakan analytics.
  • Tidak menggunakan advertising SDK.
  • Tidak menjual atau membagikan data pribadi.
  • No user accounts.
  • No data collection servers.
  • No analytics services.
  • No advertising SDKs.
  • No sale or sharing of personal data.

Aplikasi tidak memerlukan izin INTERNET untuk fungsi utamanya.

The app does not require the INTERNET permission for its core functionality.

6. Izin Android 6. Android Permissions

Beberapa fitur memerlukan izin khusus Android. Anda dapat mengelola atau mencabut izin tersebut melalui pengaturan sistem.

Some features require special Android permissions. You can manage or revoke these permissions through your system settings.

Akses Notifikasi Notification Access

Digunakan untuk mendeteksi dan memproses notifikasi yang diperlukan oleh fitur pengingat. Akses ini aktif setelah Anda memberikan persetujuan melalui Android.

Used to detect and process notifications required by reminder features. This access is enabled only after you grant permission through Android.

Notifikasi Aplikasi App Notifications

Digunakan untuk menampilkan notifikasi pengingat yang dibuat oleh ReNotification!.

Used to display reminder notifications created by ReNotification!.

Alarm dan Pengingat Terjadwal Scheduled Alarms and Reminders

Fitur tertentu menggunakan penjadwalan Android agar pengingat berjalan sesuai waktu. Jika izin alarm tepat tidak tersedia, aplikasi dapat menggunakan mekanisme alternatif dengan keterbatasan ketepatan waktu.

Certain features use Android scheduling to run reminders at the intended time. If exact alarm access is unavailable, the app may use an alternative scheduling method with reduced timing precision.

7. Keamanan dan Privasi 7. Security and Privacy

Data disimpan dalam ruang penyimpanan internal Android yang dilindungi oleh mekanisme sandbox sistem operasi.

Data is stored in Android's internal storage, protected by the operating system's sandbox.

ReNotification! tidak menyediakan enkripsi database khusus pada tingkat aplikasi. Keamanan data juga bergantung pada keamanan perangkat, pengunci layar, dan sistem operasi Android Anda.

ReNotification! does not provide separate app-level database encryption. Data security also depends on your device security, screen lock, and Android operating system.

Notifikasi pada layar kunci mengikuti pengaturan privasi Android dan dapat ditampilkan secara terbatas untuk mengurangi paparan informasi.

Lock-screen notifications follow Android privacy settings and may be displayed in a redacted form to reduce information exposure.

8. Retensi dan Penghapusan Data 8. Data Retention and Deletion

Data disimpan selama diperlukan untuk fungsi aplikasi atau sampai Anda menghapusnya.

Data is retained as long as necessary for app functionality or until you delete it.

Anda dapat menghapus data melalui fitur penghapusan riwayat yang tersedia di aplikasi, jika berlaku.

You can delete data through the app's history deletion feature, where available.

Menghapus data aplikasi melalui pengaturan Android atau mencopot aplikasi akan menghapus data lokal terkait sesuai mekanisme Android.

Clearing app data through Android settings or uninstalling the app removes associated local data according to Android's system behavior.

9. Layanan Pihak Ketiga 9. Third-Party Services

ReNotification! tidak mengintegrasikan SDK iklan, analytics, atau layanan pelacakan pihak ketiga untuk mengumpulkan data pengguna.

ReNotification! does not integrate advertising SDKs, analytics, or third-party tracking services to collect user data.

Aplikasi menggunakan fitur dan API Android yang disediakan oleh sistem operasi untuk menjalankan fungsi yang diminta pengguna.

The app uses Android system features and APIs to perform functions requested by the user.

10. Privasi Anak 10. Children's Privacy

ReNotification! tidak dirancang untuk mengumpulkan informasi pribadi anak-anak. Aplikasi tidak memiliki akun, pengumpulan data online, atau sistem profil pengguna.

ReNotification! is not designed to collect personal information from children. The app does not have accounts, online data collection, or user profiling systems.

11. Perubahan Kebijakan 11. Policy Changes

Kebijakan Privasi ini dapat diperbarui apabila terdapat perubahan fitur atau persyaratan yang relevan. Versi terbaru akan dipublikasikan di halaman ini beserta tanggal pembaruan.

This Privacy Policy may be updated when relevant features or requirements change. The latest version will be published on this page along with its revision date.

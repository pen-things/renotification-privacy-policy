SECTION 01

Informasi & Pemrosesan Data

ReNotification! dapat mengakses informasi notifikasi yang diperlukan untuk menyediakan fungsi pengingat ulang. Informasi tersebut dapat mencakup nama aplikasi sumber, judul notifikasi, isi pesan, dan informasi terkait notifikasi.

Informasi diproses secara lokal untuk menjalankan fungsi aplikasi, seperti sesi pengulangan notifikasi dan riwayat.

ReNotification! tidak memiliki akun pengguna dan tidak mengirim informasi notifikasi ke server pengembang.

Information & Data Processing

ReNotification! may access notification information required to provide reminder functionality. This may include the source app name, notification title, message content, and related notification details.

This information is processed locally to provide app features, such as notification repeat sessions and history.

ReNotification! does not have user accounts and does not send notification information to developer servers.
SECTION 02

Penyimpanan Lokal & Backup Android

Penyimpanan Lokal: Seluruh pemrosesan dan penyimpanan data dilakukan secara lokal di penyimpanan internal perangkat, termasuk database Room SQLite renotification_db, Preferences DataStore renotification_prefs, dan preferensi pemulihan volume sementara renotification_volume_recovery_prefs.xml.

Keamanan data lokal bergantung pada sandbox aplikasi Android dan enkripsi perangkat bawaan sistem operasi.

Tidak Ada Transmisi ke Server: Aplikasi tidak mendeklarasikan izin INTERNET, tidak memiliki akun/login, dan tidak menggunakan SDK pihak ketiga untuk analitik, iklan, atau pelacakan.

Perilaku Android Auto Backup:

  • Database Room renotification_db yang berisi sesi pengulangan dan riwayat notifikasi, termasuk judul dan isi pesan, serta file pemulihan volume sementara renotification_volume_recovery_prefs.xml, dikecualikan secara eksplisit dari Android Cloud Auto Backup dan transfer antarperangkat melalui aturan backup aplikasi.
  • Jika fitur backup bawaan Android diaktifkan pada perangkat, preferensi aplikasi non-sensitif yang disimpan di Preferences DataStore renotification_prefs, seperti bahasa, tema, font, warna dinamis, status onboarding, toggle notifikasi status, timestamp layanan lokal, dan penghitung filter non-pribadi, dapat tercakup dalam backup standar Android. DataStore tersebut tidak menyimpan judul atau isi notifikasi.

Privasi Layar Kunci: Notifikasi pengingat ulang menerapkan VISIBILITY_PRIVATE dengan versi layar kunci yang disamarkan untuk mencegah isi pesan sensitif ditampilkan pada layar terkunci.

File Audio Kustom: Jika pengguna memilih file audio sendiri melalui pemilih file Android, aplikasi hanya membaca file audio yang dipilih menggunakan Storage Access Framework tanpa meminta izin akses penyimpanan luas.

Local Storage & Android Backup

App-Managed Local Storage: All processing and storage occur locally in Android internal app storage, including the Room SQLite database renotification_db, Preferences DataStore renotification_prefs, and temporary volume-recovery state renotification_volume_recovery_prefs.xml.

At-rest protection relies on the Android application sandbox and standard OS device encryption.

No Transmission to Developer Servers: The app does not declare the INTERNET permission, does not require accounts or login, and includes no third-party analytics, advertising, or tracking SDKs.

Android OS Backup Behavior:

  • The Room database renotification_db containing repeat sessions and notification history, including notification titles and message content, as well as temporary volume-recovery preferences renotification_volume_recovery_prefs.xml, are explicitly excluded from Android Cloud Auto Backup and device-to-device transfer through the app's backup rules.
  • If Android's built-in device backup is enabled, non-sensitive application preferences stored in Preferences DataStore renotification_prefs, such as language, theme, font, dynamic color, onboarding status, status notification toggles, local service timestamps, and non-personal filter counters, may still be included in standard Android OS-managed backup. These preferences contain no notification titles or message content.

Lock Screen Privacy: Reminder notifications apply VISIBILITY_PRIVATE with a redacted lock-screen public version to help prevent sensitive message content from being exposed on locked screens.

Custom Audio Files: If users select their own audio file through Android's system file picker, the app only accesses the selected file using the Storage Access Framework without requesting broad storage permissions.

SECTION 03

Izin Aplikasi

ReNotification! memerlukan izin sistem tertentu agar fungsi pengingat notifikasi dapat berjalan. Izin hanya digunakan untuk fungsi yang berkaitan dengan fitur aplikasi.

Anda dapat meninjau, mengelola, atau mencabut izin melalui pengaturan Android kapan saja. Pencabutan izin tertentu dapat menyebabkan fitur terkait tidak berfungsi.

App Permissions

ReNotification! requires certain system permissions for notification reminder functionality. Permissions are used only for features associated with the app.

You can review, manage, or revoke permissions through Android settings at any time. Revoking certain permissions may prevent related features from working.
